# Similization

**Play it:** https://ge0ffr3y.github.io/similization/

CivSim is a hands-off "world history machine". A world is generated from a seed and one small band of humans appears. Over thousands of years, the simulation writes its own history: migration, farming, states, trade, faiths, wars, great people, and in the end conquest, cultural dominance, religious unity, world peace, extinction, or the long history. Nobody plays it: pick a seed, press play, and watch.

This repository only holds the built web app. It is published automatically from the project's (currently private) source repository on each release.
